# Sources

The API facts in these docs come from WeatherFlow's pages and from the API's own responses.

- [API documentation](https://apidocs.tempestwx.com)
- [Getting Started](https://weatherflow.github.io/Tempest/api/)
- [OAuth 2.0](https://weatherflow.github.io/Tempest/api/oauth.html)
- [WebSocket reference](https://weatherflow.github.io/Tempest/api/ws.html)
- [UDP v171](https://weatherflow.github.io/Tempest/api/udp/v171/)
- [Swagger file](https://weatherflow.github.io/Tempest/api/swagger/swagger.json)
- [Remote Data Access Policy](https://weatherflow.github.io/Tempest/api/remote-developer-policy.html)

The apidocs site only renders with JavaScript. When a page is hard to read, the GitHub pages above and the swagger file say the same things.

Where a page disagrees with the API, the API wins. <doc:field-notes> lists the differences that matter.

TempestKit isn't made by, endorsed by or supported by WeatherFlow. "Tempest" is their product name, used here so you know what the package talks to.
