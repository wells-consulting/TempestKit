# How this code was written

I'd rather say this up front than have it come up in a comment thread.

The code here is a mix of things I wrote by hand and things written or refactored with an AI agent.

The agent configuration files are checked in, so you can see how the agents were set up. A commit an agent helped with ends in a trailer naming the model. If there's no trailer, no agent was involved.

I read the diffs and run the tests before anything goes in. I don't catch everything, and a test that passes isn't the same as code I understand. If something here is broken, that's on me, not on the model.

If you find a problem, open an issue. I'd rather hear about it than have it sit there.
